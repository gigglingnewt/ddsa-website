# Dover & District Skittles Association - HTML Website

A clean, responsive HTML/CSS/JavaScript website for the Dover & District Skittles Association.

## Deploy

This repo is connected to Netlify for auto-deploy on push to `main`. Editing `index.html`, `css/style.css`, or `js/script.js` and pushing to `main` will automatically update the live site at dover-skittles.co.uk.

## Structure

- `index.html` - all pages
- `css/style.css` - styling
- `js/script.js` - navigation and interactivity
- `images/` - logo and page images (add via GitHub web upload)
- `pdfs/` - downloadable rules/practices documents (add via GitHub web upload)

## Brand

- Primary blue `#2292FE`, secondary `#029BE5`
- Font: Arial / Segoe UI system stack
